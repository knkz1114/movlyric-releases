# movlyric

音源と歌詞から歌詞アニメーション動画（リリックビデオ）を作るデスクトップアプリです。
このリポジトリは **配布物とリリースノートの置き場**で、アプリのアップデート確認もここを参照します。

- **公式サイト**: <https://movlyric.konalab.work>
- **Discord サーバー**: <https://discord.gg/YStms87pzy>
- **pixivFANBOX（サポーター）**: <https://konalab.fanbox.cc/>
- **ダウンロード**: [Releases](../../releases)

解析（音源分離・ビート推定・歌詞タイミング推定）はすべて**あなたの PC 上**で動きます。
音源・歌詞・映像が開発者のサーバーへ送られることはありません。

---

## はじめに必要なもの

**利用には（無料版を含め）Discord アカウントでのログインと、上記 Discord サーバーへの参加が必要です。**
先にサーバーへ参加してからアプリを起動してください。認証は Discord OAuth2 で行い、
アプリが扱うのはユーザー識別子とサーバー参加状況だけです。

## 動作環境

| | 必要なもの |
| --- | --- |
| **macOS** | **Apple Silicon（M1 以降）** / macOS 13 以降。**Intel Mac には対応していません** |
| **Windows** | Windows 10 / 11 の **64bit**。CUDA 版は NVIDIA GPU が必要 |
| 空き容量 | 本体 1〜6GB + 音声認識モデル 最大約 3GB + 曲ごとの解析キャッシュ（1 曲あたり 50〜130MB） |

音声認識モデルは初回解析時にダウンロードされます（選んだサイズによって最大約 3GB）。
解析キャッシュはアプリの設定画面から一括・個別に削除でき、上限を決めて古いものから自動削除もできます。

## ダウンロード

[Releases](../../releases) から、環境に合うものを選んでください。

| ファイル | 対象 |
| --- | --- |
| `movlyric-<version>-arm64.dmg` | **macOS（Apple Silicon）** |
| `movlyric Setup <version>.exe` | **Windows（標準）** — CPU で解析します |
| `movlyric Web Setup <version>.exe` + `movlyric-<version>-x64.nsis.7z` | **Windows（CUDA 版）** — NVIDIA GPU で解析します |

### Windows: 標準版と CUDA 版のどちらを選ぶか

**NVIDIA GPU を積んでいないなら標準版**を選んでください。CUDA 版は GPU が無いと動きません。

NVIDIA GPU がある場合、CUDA 版は音源分離と歌詞整列を GPU で実行するため解析が速くなります。
そのかわりダウンロードが約 2.3GB、インストール後は約 5GB を使います（標準版は約 610MB / 約 1.6GB）。

どちらを使っているかは、解析中の画面に出る「解析デバイス」で確認できます。

### CUDA 版のインストール手順（重要）

CUDA 版は**ファイルが 2 つに分かれています。両方を同じフォルダに置いてから**
`movlyric Web Setup <version>.exe` を実行してください。

1. `movlyric Web Setup <version>.exe` をダウンロード
2. `movlyric-<version>-x64.nsis.7z` を**同じフォルダに**ダウンロード
3. `movlyric Web Setup <version>.exe` を実行

`.7z` を自分で展開する必要はありません。インストーラが読み取ります。
片方だけだとインストールできないので注意してください。

## インストール時の警告について

**movlyric はコード署名をしていません。** そのため OS が「開発元を確認できない」旨の警告を出します。
これは個人開発のため署名証明書を取得していないことによるもので、下記の SHA256 を照合すれば
配布物が改ざんされていないことを確認できます。

### macOS

`.dmg` を開き、`movlyric.app` を「アプリケーション」フォルダへコピーしてから起動します。
「開発元が未確認のため開けません」と表示された場合は、以下のいずれかの方法で対処します。

#### 方法1: 右クリックから開く

Finder で `movlyric.app` を右クリック（または Control キー + クリック）→「開く」を選択 →
確認ダイアログで「開く」をクリック。**この操作は初回のみ必要**で、以降は通常どおり
ダブルクリックで起動できます。

#### 方法2: xattr コマンドで隔離属性を削除

```bash
xattr -cr /Applications/movlyric.app
```

`xattr -cr` は、macOS がダウンロードしたファイルに付与する隔離属性（`com.apple.quarantine`）を
再帰的に削除します（`-c` はすべての拡張属性を削除、`-r` はディレクトリ内を再帰的に処理する
オプションです）。これにより Gatekeeper によるブロックが解除されます。

macOS 15 以降で方法1 が効かない場合は、一度起動を試みたうえで
**システム設定 → プライバシーとセキュリティ**を開き、下の方に出る「このまま開く」を押すか、
方法2 を使ってください。

### Windows

SmartScreen が「WindowsによってPCが保護されました」と表示します。
**「詳細情報」→「実行」**で進めてください。

インストール先は `%LOCALAPPDATA%\Programs\movlyric` に固定しています（変更できません）。
これは誰でも書き込める場所へ入れられると、同じ PC の別アカウントに実行ファイルを
差し替えられてしまうためです。

## 配布物の完全性確認（SHA256）

各リリースのリリースノートに、全ファイルの SHA256 を記載しています。

```powershell
# Windows (PowerShell)
Get-FileHash ".\movlyric Setup 1.0.0.exe" -Algorithm SHA256
```

```bash
# macOS
shasum -a 256 movlyric-1.0.0-arm64.dmg
```

表示された値がリリースノートの値と一致すれば、ダウンロードは正常です。

## 無料版とサポーター版

**違いは 2 点だけです。**

| | 無料版 | サポーター版 |
| --- | --- | --- |
| 書き出し形式（MP4 / WebM / MOV / WebP） | すべて | すべて |
| 解像度（最大 4K = 3840×2160） | ○ | ○ |
| フレームレート | 24 / 30 fps | 24 / 30 / **60 fps** |
| **透過（アルファ）書き出し** | — | **○** |

歌詞編集・解析・スタイル・カスタムの動き / 配置 / 背景エフェクトは、**無料版でも制限なく**使えます。

サポーター版は **[pixivFANBOX のサポータープラン](https://konalab.fanbox.cc/)** への加入で
有効になります。加入すると Discord のサポーターロールが**自動で付与されます**
（Discord アカウントと pixivFANBOX の連携が必要です。手順は
[Discord サーバー](https://discord.gg/YStms87pzy) で案内しています）。

加入直後は、アプリの **設定 →「アカウント」→「ロールを再確認」**を押すとすぐ反映されます
（ログインし直す必要はありません）。

## 使い方

表示言語はセットアップ画面のフッターの「設定」から切り替えられます。
